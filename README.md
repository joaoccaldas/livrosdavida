# Livros da Vida

Digital book creation and reading platform (Portuguese). Create, edit, and browse personal picture books.

## Features

- Book creation with page-by-page editor
- Markdown rendering for page content
- Image support for book covers and pages
- Library management with grid view

## Getting Started

Open `index.html` in a browser.
